1. Large-Scale Persian G2P via ByT5 Fine-Tuning

Soroush Soleimani • Byte-Level Seq2Seq • 116K+ KaamelDict Corpus
GitHub Repository Kaggle Notebook

Persian is written in an abjad script that omits short vowels (/æ/, /e/, /o/), the grammatical Ezafe enclitic (/-e/, /-je/), and consonant gemination (tashdid). This project fine-tunes a byte-level encoder-decoder transformer (ByT5) on 115,221 instances compiled from the authoritative KaamelDict corpus. By processing raw UTF-8 bytes without subword tokenization, the model eliminates out-of-vocabulary failures and dramatically improves Persian pronunciation accuracy in downstream TTS engines.

2. End-to-End Persian G2P with VITS TTS

Melika Parhiz • Coqui VITS Architecture • ManaTTS Corpus (114h)
GitHub Repository Kaggle Notebook

A complete, train-from-scratch single-speaker Persian TTS system utilizing the Coqui VITS framework with an explicit, mandatory G2P front-end. Persian text is converted to strict phoneme sequences via Homo-GE2PE-Persian, eliminating ambiguous graphemic pronunciations before entering the VITS text encoder. The model is trained on the high-quality 114-hour ManaTTS corpus, producing natural rhythm and fluent intonation.

3. F5-TTS Architecture Analysis & Flow-Matching Fine-Tuning

Soroush Soleimani • Non-Autoregressive Flow Matching • Diffusion Transformer (DiT)
Architecture Explanation Fine-Tuning Notebook

An exhaustive mathematical and implementation study of F5-TTS, the pioneering non-autoregressive speech synthesis architecture based on Conditional Flow Matching (CFM) and a Diffusion Transformer (DiT) backbone with ConvNeXt-V2 text refinement. The project details how F5-TTS eliminates duration predictors and complex phoneme aligners through continuous-time vector field modeling, paired with end-to-end fine-tuning workflows on Kaggle GPU for zero-shot voice cloning.

4. English TTS Engine with VITS Architecture

Melika Parhiz • VITS Implementation • LJSpeech-1.1 Benchmark
GitHub Repository

A local training and synthesis pipeline implementing the original VITS architecture (Variational Inference with adversarial learning for end-to-end Text-to-Speech). Features a Transformer text encoder, normalizing flows, variational posterior encoder, stochastic duration predictor, and multi-period discriminators trained on mono PCM16 22,050 Hz LJSpeech-1.1 data. Includes clean checkpoint resumption, Monotonic Alignment Search (MAS), and unit test validation suites.
